5. Why the review looks like this

Explain cheapest candidate is the half‑precision candidate to validate first because it uses least energy per inference and lowest latency although it draws more power while running than the eight‑bit builds.

The position fine‑tune (same half‑precision engine cost) removed the start‑position weakness shown at both held‑out shifts giving clear improvement but it has not yet shown nominal performance at the training mark because the comparison there is undecided.

Success comparisons against full precision cannot be decided yet because the confidence intervals for each candidate cross the tolerance band leaving the evidence insufficient.

The deliberately miscalibrated builds are stopped at the simple input check because that check catches the bad calibration before any other test runs.

The AI judge’s record shows it is wording‑sensitive looks only at the final state gives more false alarms on novel objects so it must be re‑validated before reliance it cleared re‑check on fresh live trials in the fine‑tune study but still needs checking on other objects and scenes.

FP32 and ten INT8 cells, interleaved in one blinded session. Every interval overlaps FP32. At these sample sizes no cell can be shown to be within 10 pp of FP32 either, so each one is "insufficient evidence", not "safe". The INT8 cells differ only in calibration: sample count, data composition and per-tensor or per-channel scaling.

Best vs worst fidelity on placement (AEP Q1, E2): −0.84 px, 97.5% CI [−2.53, +0.88], tolerance-compatible with the 5 px tolerance. On success (E1) the ceiling rule applies, so the decision is indeterminate. The AEP claim is not falsified here.

Engine cost on the deployment target

trtexec · tegrastats 100 ms · power_bench/SUMMARY.md

FP16 is the fastest and the cheapest per inference. INT8 draws about 1 W less while it runs but takes 45% longer, so each inference costs more. The three INT8 calibrations cost the same.

End to end in the trial runner, including preprocessing and the socket round trip, the same order holds: FP16 24.7 ms, INT8 34.3 ms and FP32 79.0 ms (FP16 block). On the real arm FP16 succeeded 19/20, with placement within tolerance of FP32.

What moved the success rate

G6 + public stress tallies

The same arm and the same policy. Between precisions no success difference was detected. Grip friction and a 3 cm shift moved a lot. The gripper and shift blocks are separate sessions, so read them as observations, not as a randomized comparison.
