# attempt-031 — `G2` FP32 기준선 실기 20 trial: **20/20 성공**, `K1` 미발동

## 설정

- 정책: G2 100k 체크포인트, Orin TRT FP32 엔진(`--noTF32`, `c3e75e15…`) = 실기 `VC-000`
- 실행: 30Hz, 최대 60초, chunk 100, 10스텝 전 미리 요청 + 경계 4스텝 섞기(decision_log 2026-10-07 최종 확정)
- 판정: 자동(목표 영역 = 컵받침 전체, 서 있음, 정지) + 조작자(놓음, 사람 개입). 판정 규칙 잠금 `success_criterion_lock.sha256`
- 세션 전 점검: 조명 PASS, 손목 PASS(기준 재저장 후), 컵받침 PASS
- 조작자는 셀을 안다(G2는 단일 arm, 블라인드 대상 아님)

## 해석과 위험

- `K1`(FP32 < 70%) **미발동**. G6로 간다
- **`K2` 위험이 크다.** 사전등록 §2.1은 FP32 70–90%를 목표 마진으로 두었는데 20/20이다. 목표 영역은 결과 전에 컵받침 전체로
  잠갔으므로 바꾸지 않는다. INT8 셀도 거의 다 성공하면 `K2`(G6 중간, 각 셀 8 trial)가 발동하고, 사전등록대로 "이 체제에서 INT8은
  양성"이라는 음성 결과로 보고한다 — 과제를 바꿔 효과를 찾지 않는다
- 바닥 중심 거리 분포(3.9–11.1px)는 셀 간 차이를 볼 수 있는 연속 지표지만, 사전등록된 엔드포인트가 아니다. 쓰려면 탐색적 분석으로만 표시한다

## 주장하지 않는 것

- 20/20은 FP32 정책 하나의 이 조건(같은 시작 위치, 같은 캔, 같은 조명)에서의 결과다. 일반화 주장이 아니다
