# Progress notes

AEP(`~/workspace/AEP/docs/progress`)와 같은 관례를 따른다.

- 파일명: `YYYY-MM-DD_attempt-NNN_짧은-슬러그.md`
- `NNN`은 이 리포 기준으로 001부터 순증. 되돌리거나 재사용하지 않는다
- 시도(attempt) 1회 = 노트 1개. 실패한 시도도 노트를 남긴다

각 노트의 필수 섹션:

| 섹션 | 내용 |
|---|---|
| Scope | 이 시도가 **건드린 범위와 건드리지 않은 범위**. 특히 실기·학습·빌드를 돌리지 않았으면 명시 |
| 변경 | 무엇을 만들었고 무엇을 고쳤는가 |
| 관측 | 실행해서 나온 것. **합성 데이터 결과는 합성이라고 쓴다** |
| Verification | 통과한 검증과 **통과하지 못한 것**. 미완·우회·미측정을 숨기지 않는다 |
| 주장하지 않는 것 | 이 시도가 근거를 제공하지 **않는** 명제 |

마지막 섹션이 핵심이다. 사전등록 연구에서 노트는 "무엇을 했나"보다
"무엇을 근거로 쓸 수 있나"를 기록하는 장치다 (사전등록 §13).
