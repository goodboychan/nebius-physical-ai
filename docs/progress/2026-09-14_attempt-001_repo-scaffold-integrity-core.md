# 리포지토리 스캐폴드와 무결성 코어

## Scope

사전등록 v0.1 기준. `D1`(공개 리포 + Apache 2.0) 착수와 §3–§4의 무결성 장치 구현만 다룬다.

**하지 않은 것**: 데이터 수집 없음, 정책 학습 없음, ONNX/TRT 빌드 없음, 실기 trial 없음,
Nebius 호출 없음. 로봇 팔은 아직 도착하지 않았고 이 시도는 팔과 무관하다.

## 관측

전부 **합성 데이터** 위의 동작 확인이다. 실제 에피소드는 0개다.

- `grid_hash = 9b33287e63c344c6d8f4fb0837b75344e71693f58ac6bce2ede502cb5da1393c`
  (26셀: `VC-000` FP32, `VC-001`–`VC-024` INT8, `VC-025` FP16)
- 가짜 120 에피소드에서 분할 80/20/20 생성. 입력 순서를 뒤집어도 manifest 해시 동일 —
  수집 순서(= 시간 드리프트)가 분할에 새어들지 않음을 확인
- `IG-1` 가드가 audit→calibration, val→calibration 두 경로 모두에서 예외를 던짐
- 길이 편차가 있는 가짜 에피소드에서 에피소드당 정확히 100 상태, 총 2,000 상태, 중복 없음
- 부트스트랩 인덱스가 (시드, replicate)에 대해 재현되고 replicate 간에는 다름

## Verification

- 위 항목은 **스모크 수준**이다. 아직 `pytest` 스위트가 없다 — attempt-002 이후로 미룸
- TRT·ONNX 경로는 이 시도에서 전혀 건드리지 않았다. `G0`의 통과 기준
  ("TRT INT8 빌드가 한 번이라도 성공")은 **미충족**이다
- Nebius 자격증명이 환경에 없어 Jobs 더미 팬아웃(§14 액션 4)은 시작하지 못했다

## 주장하지 않는 것

- 양자화, 정책 성능, 로봇 동작에 관한 어떤 경험적 명제도 이 시도는 뒷받침하지 않는다
- 해시가 생성되었다는 것은 값이 **고정되었다**는 뜻이지 그 값이 **옳다**는 뜻이 아니다
- `docs/success_criterion.md`는 아직 잠기지 않았다. 현재 상태로는 `IG-6`을 충족하지 않는다
