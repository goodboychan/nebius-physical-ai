# 성공 판정 규칙 (`IG-6`)

**문서 상태**: DRAFT — 최초 실기 trial(= `G2`의 FP32 기준선 20 trial) 이전에 잠근다.
잠금 이후 실행 중 수정은 금지(`IG-6`). 잠금은 `scripts/freeze.py`로 해시를 커밋하여 수행한다.

참조: 사전등록 §2.1, §8. 2026-10-06에 과제 변경(슬롯 삽입 → 캔 옮겨 세우기)에 맞춰 다시 썼다.

---

## 1. 판정 대상

캔 옮겨 세우기(pick-and-place) 1회 trial의 **이진 성공/실패**. 부분점수 없음.
대상물: 따지 않은 콜라캔 268g (예비 캔은 ±5g). 목표: 책상에 양면테이프로 고정한 컵받침.

## 2. 성공의 정의

다음을 **모두** 만족하면 성공:

1. trial 시작 신호로부터 **60.0초 이내**에 종료 조건 도달
2. 종료 시점에 캔이 **목표 영역 안에 서 있음** — 아래 §3의 기하 기준 충족
3. 종료 시점에 집게가 캔을 **놓은 상태** (집게가 캔에서 떨어져 있음)
4. 구간 전체에서 **사람의 물리적 개입 없음** (접촉, 위치 보정, 재파지 보조 모두 개입으로 간주)

하나라도 불만족이면 실패. 실패는 §5의 유형 중 정확히 하나로 분류한다(`EX-1`).

## 3. "목표 영역 안에 서 있음"의 기하 기준

판정자: 오버헤드 카메라 프레임 + 목표 영역 기준 좌표.

- 목표 영역은 컵받침 위치로 정의한다. 카메라·컵받침·조명이 고정된 상태에서 세션 시작 시
  1회 확인한다(§2.3).
- 안에 서 있음 = 오버헤드 화면에서 캔 윗면(원) 중심이 목표 영역 안에 있고, 캔이 서 있으며,
  연속 0.5초 동안 프레임 간 변위가 임계 이하로 정지.
- 목표 영역(컵받침 전체 또는 안쪽 원), 임계값, 기준 좌표는 잠금 시점에 이 문서에 수치로 박아 넣는다.

## 4. 애매한 케이스 처리 규칙

아래는 잠금 전에 전부 확정해야 한다. 실행 중 새 규칙 추가 금지.

| 케이스 | 판정 |
|---|---|
| 60초 경계 (59.x ~ 60.x초) | 프레임 타임스탬프 기준. 60.000초 초과 프레임에서 최초 충족 → **실패(timeout)** |
| 목표에 놓은 뒤 60초 이내에 넘어지거나 밀려남 | **실패(drop)**. 종료 시점 기준으로 판정 |
| 캔 중심이 목표 영역 경계에 걸침 | 기준 좌표로 판정. 중심이 영역 밖이면 **실패(miss)** |
| 목표 안에 서 있으나 집게가 아직 쥐고 있음 | 60초 안에 놓지 않으면 **실패(timeout)** |
| 기울어져 서 있음 (넘어지지 않음) | 정지 상태면 **성공** (자세는 기준에 포함하지 않음) |
| 캔이 넘어짐 (옆으로 누움) | **실패(drop)** |
| 캔이 워크스페이스 밖으로 이탈 | **실패(drop)** |
| 팔이 컵받침·캔과 충돌 후 계속 진행하여 성공 | **성공**, 단 `EX-1`에 collision 부수 플래그 기록 |
| 충돌로 컵받침이 움직임 | **실패(unsafe)** + 해당 trial 이후 컵받침 재정렬, 재정렬 사실을 세션 로그에 기록 |
| 캔이 찌그러짐 | 판정은 위 기준대로. trial 후 캔 교체, 교체 사실을 세션 로그에 기록 |
| 런타임 감독자(`D4`)가 abort | **실패(unsafe)**. `D4` 개입은 `EX-3`에 별도 기록하되 성공률 계산에서 예외 처리하지 않는다 |
| 클라우드 폴백(`D6`) 발동 후 성공 | **실패**로 집계한다. 주 엔드포인트 `EP-1`은 **엣지 정책 단독** 성공률이다. 폴백 성공은 `EX-3`에 별도 보고 |
| 프레임 손실·녹화 실패로 판정 불가 | **무효 trial**. 성공/실패 어느 쪽으로도 집계하지 않고, 동일 셀에 대해 재시행하며 무효 발생을 로그에 남긴다 |

무효 trial은 §7의 표본 수에서 제외되고 재시행으로 채워진다. 무효율이 5%를 넘으면
그 사실 자체를 결과에 보고한다.

## 5. 실패 유형 (`EX-1`, 상호배타)

우선순위 순으로 최초 해당하는 것 하나만 부여한다.

1. `unsafe` — 안전 개입/abort/컵받침 이탈
2. `timeout` — 60초 내 미충족
3. `drop` — 파지 후 놓침, 캔 넘어짐, 또는 놓은 뒤 이탈
4. `collision` — 충돌로 진행 불가
5. `miss` — 파지 실패, 또는 목표 영역 밖에 놓음

## 6. 판정자와 블라인딩

- 판정은 **오버헤드 영상 기준**으로 하며, 판정 시점에 조작자는 어느 변형이 돌았는지 모른다(`IG-5`).
- 봉인 로그는 `LOCK-3`(120 trial 완료) 이후에만 해제한다.
- 애매 케이스는 위 표에만 의존한다. 표에 없는 상황이 나오면 **그 trial을 무효 처리**하고,
  규칙을 고치지 않은 채 사유를 기록한다. 규칙 추가는 실기 종료 후 개정으로만 가능하다.
